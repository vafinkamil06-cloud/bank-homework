# Домашнее задание: банковский счёт

- **Группа: 09-413** 
- **ФИО: Вафин Камиль Ильнурович** 

## Что реализовано

- `Currency`: enum валют с курсом в копейках.
- `Balance`: неизменяемый (final) баланс: сумма в копейках + валюта; `add`, `subtract`, `convertTo`.
- `BankAccount`: счёт с балансом, `deposit`, `withdraw`, `transfer` между счетами (в том числе в разных валютах).
- Дополнительно: дневной лимит на вывод, заморозка счёта, история операций.
- `Main`: демонстрация работы и корнер кейсов.

## Запуск

```
javac -encoding UTF-8 -d out src/bank/*.java
java -cp out bank.Main
```
